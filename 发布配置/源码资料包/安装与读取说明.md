# 动效源码包

包名：`@xuge1324652022-boop/animation-source-package`，当前版本：`0.2.4`。

这是求职者应聘模板网站的源码资料包，包含 38 个效果各自的中文源码、集成示例、使用说明和 JSON 解析。适合其它 agent 读取、学习与迁移。包中保留中文目录和文件名；`package.json`、`README.md`、`LICENSE` 等为 npm 的标准文件名。

0.2.4 配套展示匿名求职模板，人物、经历和联系方式均为明确虚构的模板资料，示例联系域名为 example.com。源码引用的图片与视频为程序合成示例，示例简历明确标注模板用途；包不包含私人简历、肖像、个人站点地址或历史输出。旧版本的隐私清理情况需单独核对，不能把新版脱敏理解为旧版已经移除。

本版加入 ChatGPT、Codex、DeepSeek 的项目协作署名。人类维护者与 AI 工具的参与关系见 [项目协作署名说明](docs/项目协作署名.md)；供 agent 读取的结构化记录见 [项目协作署名 JSON](项目协作署名.json)。署名说明随本包提供，不依赖网站或原仓库才能读取。

安装本包不需要 Vue、GSAP，也不会运行安装脚本。本包没有可直接导入的运行时入口；使用效果时，先读解析文件，再将所需源码迁移到自己的项目，并按该效果的 `npmDependencies` 安装运行依赖。

## 安装

GitHub Packages 的 npm 注册表要求身份验证，公开包安装也需要验证。请在 GitHub 创建仅含所需 `read:packages` 权限的 personal access token（classic），并在自己的终端交互登录；不要把令牌发送到聊天、写入本项目，或提交到 Git。

在消费项目的 `.npmrc` 只添加以下 scope 映射：

```ini
@xuge1324652022-boop:registry=https://npm.pkg.github.com
```

然后执行以下命令，按提示输入 GitHub 用户名和令牌：

```sh
npm login --scope=@xuge1324652022-boop --auth-type=legacy --registry=https://npm.pkg.github.com
npm install @xuge1324652022-boop/animation-source-package@0.2.4
```

scope 映射只影响本账号的包，其余依赖继续使用消费项目原有的 npm 注册表。认证信息由本机 npm 管理；如果在 CI 中安装，请通过 CI 的机密或相应仓库的 `GITHUB_TOKEN` 提供凭据。

参考：[GitHub 官方 npm 注册表说明](https://docs.github.com/en/packages/working-with-a-github-packages-registry/working-with-the-npm-registry)、[包权限说明](https://docs.github.com/en/packages/learn-github-packages/about-permissions-for-github-packages)。

## 让 agent 读取

从安装目录 `node_modules/@xuge1324652022-boop/animation-source-package/动效组件库/组件索引.json` 开始。以下 Node.js 示例适用于普通 npm 的 `node_modules` 布局，不会加载 Vue、GSAP 或浏览器代码：

```js
import { readFile } from 'node:fs/promises'
import path from 'node:path'

const 包目录 = path.resolve(
  'node_modules/@xuge1324652022-boop/animation-source-package'
)
const 组件库目录 = path.join(包目录, '动效组件库')
const 索引 = JSON.parse(await readFile(path.join(组件库目录, '组件索引.json'), 'utf8'))
const 效果 = 索引.effects.find(条目 => 条目.id === 'home-preloader')
if (!效果) throw new Error('找不到开场预加载效果')
const 解析路径 = path.join(组件库目录, 效果.manifest)
const 解析 = JSON.parse(await readFile(解析路径, 'utf8'))
const 源码入口 = 解析.bundle.entryFiles.map(相对路径 =>
  path.resolve(path.dirname(解析路径), 相对路径)
)
console.log({ 效果: 效果.title.zh, 解析路径, 源码入口 })
```

推荐读取顺序：

1. `动效组件库/组件索引.json`：效果列表、入口与定位路径。
2. 对应效果的 `效果介绍与解析.json` 与 `使用说明.md`：触发机制、状态、时间线、性能与无障碍边界。
3. `bundle.entryFiles`：可在本包中找到的中文源码入口；`sources` 记录其依赖、文件哈希和仓库原始路径。
4. `集成示例/`：原网站的调用上下文，部分上下文依赖需要从完整网站仓库补充。

`entryFiles`、`sourceSections`、`sources.original` 和 `bundle.sourceOfTruth` 中的 `src/...` 代表原网站仓库中的追溯位置；本资料包中请使用 `bundle.entryFiles`、`sources.path` 和组件索引内的路径定位中文副本。索引内的重新生成命令也只在完整仓库根目录执行。

## 迁移与许可

`源码/` 包含该效果本地导入的传递源码依赖，并已改写相对导入路径。共享文件在不同效果中会重复出现，迁移多个效果时请按原始路径识别并整合共享逻辑。`集成示例/` 只说明宿主调用方式，不保证自成完整依赖集合。效果代码可能依赖浏览器环境；请按解析中的生命周期说明挂载、清理与适配减少动态效果的偏好。

程序代码与项目文档按 `LICENSE` 中的 MIT 许可使用。图片、人物肖像、作品素材和第三方标识按 `NOTICE.md` 单独说明；公开源码不授予第三方素材的额外权利。请同时阅读 `docs/AI工具图标来源.md`。
