# 公开内容与隐私检查

公开模板只使用明确虚构的身份、教育、工作经历与演示数值，联系入口采用 example.com。图片、简历和视频均为程序生成的示例，不使用私人原件。GitHub 仓库及包的账户坐标用于安装和维护，不作为私人联系方式。

`npm run check:privacy` 检查实际待提交文件，拒绝私人目录、非示例邮箱、手机号、本机用户路径和疑似凭据；运行实际身份数据模块验证默认字段；逐个核对公开二进制与 `public/模板素材清单.json` 的 SHA-256。不能用重命名或 .gitignore 掩盖已经跟踪的私人文件。不要在检查报错中回显私人字段。

源码资料包发布前还应重新生成 38 组中文副本、真实打包、逐文件核对归档并离线安装。归档不能混入历史 ZIP、截图、资料提取文本或本机私有目录。新提交使用 GitHub noreply 身份，不能继续写入私人邮箱。

本机原件、历史输出、旧资料和脱敏审计证据保留在被忽略的目录。公开版本不自动读取这些目录，修改合成素材时需重新生成公开清单并复核内容。

## 历史清理状态

新版脱敏不会从旧 Git 提交、旧标签、Release 附件或旧包版本中删除资料。此前公开版本包含真实个人资料，旧提交元数据也存在私人邮箱；这些历史入口不能被宣称为已清除。

后续历史清理需要逐项核对并处理：旧 Release 附件与标签、旧源码包版本、所有公开分支历史、提交作者与提交者字段、工作流归档，以及可能存在的引用或缓存。历史重写会改变提交 SHA，既有克隆需重新同步；删除和重写之前应保留本机可恢复归档并确认具体范围。第三方已下载副本不由本项目控制。
