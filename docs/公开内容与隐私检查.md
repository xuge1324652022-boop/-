# 公开内容与隐私检查

公开模板只使用明确虚构的身份、教育、工作经历与演示数值，联系入口采用 example.com。图片、简历和视频均为程序生成的示例，不使用私人原件。GitHub 仓库及包的账户坐标用于安装和维护，不作为私人联系方式。

`npm run check:privacy` 检查实际待提交文件，拒绝私人目录、非示例邮箱、手机号、本机用户路径和疑似凭据；运行实际身份数据模块验证默认字段；逐个核对公开二进制与 `public/模板素材清单.json` 的 SHA-256。不能用重命名或 .gitignore 掩盖已经跟踪的私人文件。不要在检查报错中回显私人字段。

源码资料包发布前还应重新生成 38 组中文副本、真实打包、逐文件核对归档并离线安装。归档不能混入历史 ZIP、截图、资料提取文本或本机私有目录。新提交使用 GitHub noreply 身份，不能继续写入私人邮箱。

本机原件、历史输出、旧资料和脱敏审计证据保留在被忽略的目录。公开版本不自动读取这些目录，修改合成素材时需重新生成公开清单并复核内容。

公开 main 已替换为不含旧父提交的脱敏根提交，作者和提交者均使用 GitHub noreply 邮箱。旧公开分支、v0.1.0 / v0.2.0 标签及 Release（含四个手动附件）、三个旧源码包版本、三个引用旧提交的发布工作流记录均已移除。旧日志、附件、包和完整 Git 历史先备份到本机被忽略的私有目录，未删除私人原件。不要把这些旧引用再次推送。

当前有效源码包是 `@xuge1324652022-boop/animation-source-package@0.2.2`，38 个效果、524 个文件。其注册表 SHA-512 与本机独立打包检查一致；实际归档检查和离线安装均通过。官方版本管理页显示一个有效版本、两个已删除版本；旧名称包已不再提供旧版本。

历史清理尚有平台缓存尾项：匿名核查确认，脱离分支和标签的某个旧提交及其原始文件仍可读取私人资料。已通过 GitHub 官方缓存清理助手提交申请并收到工单已创建的确认，等待平台处理；在平台确认并经匿名复核之前，不能宣称旧个人资料已彻底从 GitHub 消失。公开说明不列出私人旧提交直链，相关证据只保留本机私有目录。第三方已下载副本不由本项目控制。

历史重写会改变提交 SHA；既有克隆应重新克隆或以脱敏 main 为基线迁移修改，不能通过合并旧历史恢复。新版的隐私检查、公开素材白名单和发布归档验证必须继续作为交付门禁。
