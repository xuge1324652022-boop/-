# 代码维护指南

本次注释整理覆盖 `src/` 中的 Vue、TypeScript、JavaScript、CSS，以及根入口、构建配置和素材脚本。说明侧重模块职责、数据来源、状态转换、时序、性能取舍和资源释放，不把显然语法逐行翻译。JSON 不插入注释，避免破坏解析。

## 从哪里读起

按视觉效果找源码与机器可读解析，可从 [动效组件源码库](../动效组件库/使用说明.md) 和 [组件索引.json](../动效组件库/组件索引.json) 进入。每种效果有中文独立目录、真实源码/依赖、`效果介绍与解析.json`、集成上下文与验证说明。应用源码仍维护在根目录 `src/`；修改后运行 `npm run build:motion` 更新快照，`npm run check:motion` 检查一致性，Cloudflare 构建同样执行此检查。

## 必须保留的边界

- App 负责“何时换页”，PageCurtain 负责“如何覆盖”；导航序号让旧异步任务失去写权限。失败必须释放锁或提供重试。
- 转场覆盖完成才能更换视图；揭幕开始允许标题入场，直到揭幕完成才恢复页面滚动。
- 分行准备只针对接近视口的介绍，每帧最多准备一个区块；取消过期任务，刷新请求合并。不能在滚动帧中反复分行或测量字体。
- 一次性入场记录已读状态；重排、字体加载与反向滚动不能重新隐藏读过的内容。滚动驱动的空间场景仍可按进度回退。
- GSAP context、ScrollTrigger、定时器、原生 Animation、观察器、监听与媒体都由创建者清理，减少动态分支也须可正常卸载。
- 调色首屏最多 5 个活跃视频，遮罩/索引/标签页隐藏时停止播放；退休层缩回后卸载资源，正文仅在可见时播放。
- 简历粗体来自实际文档片段；作品清单显式登记，内部稳定 id 不随展示标题改变。保留完整画幅，源文件只读。

## 当前验证入口

先运行 `npm run typecheck`、`npm run build` 和 `git diff --check`。以下浏览器脚本针对当前结构，通常连接本机 5174；具体 URL、截图目录、浏览器路径以各脚本顶部为准。

| 检查 | 脚本（`outputs/`） |
| --- | --- |
| 六卡片与跨子页弧形转场 | `verify-page-curtain.cjs`、`verify-page-curtain-gallery.cjs` |
| 慢路由、取消、模块加载失败恢复 | `verify-page-curtain-recovery.cjs` |
| 双语分行、独立段落、重排与不重播 | `verify-about-text-pop.cjs` |
| 关于我内容、交互、手机与减少动态 | `verify-about-editorial.cjs` |
| 调色加载/播放并发、离屏与卸载 | `verify-color-entry-performance.cjs` |
| 海报逐张观看、空间切换与查看器 | `verify-poster-reference-flow.cjs` |
| 编辑与新闻入口地基 | `verify-foundation-pages.cjs` |

这些脚本依赖本机 Edge 与 `playwright-core`，旧脚本有不同端口和退役选择器，不应直接全量运行来判断新版是否通过。`profile-*.cjs` 是性能采样而非帧率保证。截图、CPU 记录和临时结果按 `.gitignore` 留本机；断言脚本和分析文档进 Git。
