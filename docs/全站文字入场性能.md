# 全站文字入场性能 · 2026-10-16

## 保留的效果

六个卡片子页沿用现有字号、排版、中英内容、遮罩弹出、缓动和时长；已读文字仍只播放一次，调整窗口不重新隐藏；减少动态模式保持静态可读

## 实测瓶颈

1440×1000、同一个本机 Edge、从卡片列表进入六页，无鼠标轨迹或媒体播放。初始样本中关于我出现 195ms 长任务，海报出现 161ms 长任务

CPU 采样定位到：

- `ReferenceIntroduction` 在 Vue mount 当轮同步分行，包括远离屏幕的介绍；首次边界读取承接了整页尚未完成的布局
- AboutHero 的首次 GSAP transform 读取、人物场景和海报堆栈的初次测量也迫使页面同步布局
- 各文字实例分别安排全局 ScrollTrigger 刷新；通用正文和编辑图版初始化还会重复刷新
- 大标题字号拟合在 mount、ResizeObserver 首次通知、字体 ready 时反复写参考字号、测 Range，再写回最终字号
- 全站弧形幕布在文字弹出期间逐帧修改 cap 高度，额外产生布局与绘制

## 实现

- `src/utils/motionLayout.ts`：可取消的共享准备队列，给原始 DOM 一次自然布局机会，再按可见优先、每帧一个组件执行；全局刷新在准备批次结束后合并执行
- `ReferenceIntroduction`：提前 500px 准备，离屏段落不在首屏分行；保留 SplitText 真实行、中文换行点、首行缩进、ARIA 和 autoSplit；外部 reveal 可显式请求准备；文本更换前恢复 Vue DOM，重排时保留播放进度
- `useFitText`：缓存实际宽度、文字和字体参数；命中时不写参考字号、不测 Range；合并字体、窗口、文字和容器变化，保留单行复核与 0.995 安全余量
- About 与海报场景：初始化测量使用同一准备队列，离开页面取消尚未执行的工作，保留已有动画生命周期
- PageCurtain：将上下弧边改为固定基高加 transform；`scaleY` 与 1% 位移保留旧版动态高度、99% 重叠的视觉几何，不再逐帧改变 height
- 章节字样保留 0.55s 延迟、0.8s 时长和原 power4.out 曲线，用预先采样的原曲线驱动浏览器原生 transform/opacity 动画，使新页准备占用主线程时章节文字仍可在合成线程推进；揭幕时把当前可见状态交回原退出淡出
- 滚动归位移到已被幕布盖住、路由守卫与懒组件均成功后的旧页面，避免 Vue 刚挂载新页就因无意义的 `scrollTo(0,0)` 触发全页同步布局；保留同页导航与首访原有行为
- 通用正文、编辑图版和剪辑/新闻页面共用刷新调度；没有图版场景时不额外全局刷新

## 验证与证据

性能样本、CPU profile 保存在 `outputs/text-performance-2026-10-16/`；入口采样脚本为 `outputs/profile-text-entries.cjs`

`outputs/verify-about-text-pop.cjs` 检查近屏准备、中文和英文各自进入、动画途中重排、播放后重排和反向滚动不重播；`outputs/verify-page-curtain.cjs` 使用真实可视边界验证六页遮罩覆盖、弧边、移动端与减少动态模式

本机采样不能替代所有设备的帧率保证；部署的媒体文件仍遵循调色页单独的资源约定

最终采样仍能看到 About/Poster 首次构建各自长页面时的一次主线程任务，不能据此声称所有设备已无掉帧；优化重点是减少重复工作，并将可见章节文字的入场从这次任务中解耦
