# 国内访问排查与域名方案

此文件是脱敏后的访问排查模板；保留排查方法，不公布发布者的个人域名候选或账户信息。示例地址并非实际部署或连通性承诺。

## 排查结果

当前地址：`https://portfolio.example.com/about`。

1. Cloudflare API 确认 Worker 公共入口已启用；使用当前可用的代理感知网络请求，页面返回 HTTP 200。
2. 分别向 `223.5.5.5`、`119.29.29.29` 查询默认域名，结果为 `185.60.216.169`、`204.79.197.217`；Cloudflare HTTPS DNS 查询返回 `104.21.80.84`、`172.67.176.87`。测试网络存在 DNS 回复不一致的现象。
3. 单次请求显式绕过代理后，普通 HTTPS 连接超时。固定到上述两个 Cloudflare IP 后，TCP 建立成功，但 TLS 握手连接被重置。

这些结果说明访问失败发生在前端页面执行之前，不能靠调整 Vue 或 GSAP 动画修复。尚不能据此确定具体网络设备或拦截机制，也不能推断所有国内运营商都相同。

测试仅逐请求绕过显式代理，没有关闭或修改系统 VPN/TUN，因此不能等同于已经完成关闭 VPN 的真实用户网络验收。

腾讯云/DNSPod 普通 `.com` 价格表当次显示：注册首年 83 元，续费 90 元/年。官网公告 2026-11-01 起调整 `.com` 价格，因此未来续费以当时结算为准；当前最终价格也以具体域名订单为准。

国内求职访问优先时，建议在国内有资质的注册商注册域名，保留后续备案和更换权威 DNS 的选择。腾讯云支持更换为其他 DNS 服务商；Cloudflare Registrar 注册期间要求使用 Cloudflare 权威 DNS。

## 建议实施顺序

1. 用户确认具体域名、注册商和订单费用，并完成注册所需的真实身份资料与付款。
2. 将确认归属后的域名接入现有 Worker，验证 HTTPS、页面深链接、图片、字体、视频 Range、简历下载和手机交互。
3. 用户关闭 VPN 后，分别在手机蜂窝网络和家庭宽带实测；有条件时增加另一运营商测试。
4. 若仍不稳定，再选择大陆托管并办理 ICP 备案，或比较香港托管的实际连通性。香港仍是跨境线路，不能承诺可达性。现有 Cloudflare 站点可保留为备用。

仅更换域名不保证国内访问恢复。Cloudflare 普通全球网络不包含中国大陆节点，国内用户通常经境外节点访问；不能通过普通账户设置把流量固定到指定城市。

当前网站资源已能完整独立部署，无须重做前端或拆分到 R2 才能换托管。
