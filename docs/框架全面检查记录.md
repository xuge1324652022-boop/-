# 模板框架全面检查

日期：2026-10-23；对应版本：0.2.4。

## 检查范围

检查八个路由 `/`、`/cards`、`/about`、`/edit`、`/color`、`/news`、`/poster`、`/photo`，覆盖图片比例、框边对齐、查看器、导航遮罩、窗口缩放、减少动态偏好，以及公开文案和素材维护脚本。

## 已修复

- 合成图像主体统一水平和垂直边界，圆形保持同一像素半径；保留各素材尺寸，清除图像元数据。横向示例的标签加入居中裁切安全边距。
- 原作品标题、地点、替代文本与产品说明改成通用合成示例；36 组图像及 108 个图片文件采用 `sample-photo`、`sample-poster` 编号。中文动效源码副本随原始源码重新生成。
- 卡片索引在中等宽度或低高度窗口使用可滚动网格；大屏扇牌把五次横向偏移计入居中。
- 首页、摄影页与卡内动效实时响应减少动态偏好；当前入场完成到可读终态，环境循环暂停，恢复后可继续，卸载时释放监听和指针补间。
- 卡片尺寸重建保留已完成的显影状态；ABOUT 在中途缩放窗口时清理自身宿主的入场样式，避免停在半透明或缩放的中间帧。
- 模板提示条置于查看器、作品索引和转场幕布之后。海报色彩章节的矮屏回退阈值与舞台最小高度一致。
- 公开图片维护工具只核验公开审核清单，不再默认读取本机原片或原始 PDF；历史处理代码保存在本机忽略目录。

## 验证与边界

浏览器在 1440×900、390×844、320×568 检查七个内容路由首屏，记录未发现横向溢出或已完成解码的破图。卡片页另核对 800×600、1024×600，以及 1440×900、1920×1080 的大屏包围盒；海报在 1024×568 使用文档流回退。

交互复核确认：首页自动进入内容页；卡片第六项通过幕布进入摄影页并释放输入锁；摄影两列上下边界一致；查看器在 320×568 和 844×390 内保留关闭、切换和缩略图控件；作品索引可用键盘展开；英文切换同步文档语言、标题并在刷新后保留，测试后恢复中文。浏览器窗口测试不能等同真实手机设备、旧微信内核或性能跑分。

逻辑回归使用实际 Vue/TS 模块与 GSAP，覆盖偏好变化、窗口重建、导航所有权、素材隔离和真实 404。新增视觉内容门禁实际读取默认素材模块，拒绝非示例标题、非合成说明、旧式素材路径、额外文件及缺失的审核条目。

完整检查命令为 `npm run build:cloudflare`；隐私检查必须在审核后的文件暂存后执行，核对实际 Git 上传字节。此命令只准备构建，不会上传私人文件。

匿名演示站的静态托管层当前整文件返回短视频和 PDF，未提供 Range 的 206/416；仓库部署实现的分段请求回归与演示托管验收分别记录。旧 GitHub 历史缓存仍需平台处理，不因本版修复而自动清除。
