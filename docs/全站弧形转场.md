# 全站弧形转场

更新日期：2026-10-16

## 参考与视觉

参考 [Dennis Snellenberg 的 About 页面](https://dennissnellenberg.com/about) 公开页面、`assets/js/index-new.js` 的 `pageTransitionIn` / `pageTransitionOut` 和 `assets/css/style-new.css` 的 loading-screen 样式；源文件快照保留于 `outputs/about-editorial-2026-10-15/`

转场按同一顺序执行：深色面板由底部覆盖当前页，显示目的章节的中文主标题与英文副标题，再以弧形下缘向上揭开新页面

| 阶段 | 参数 |
| --- | --- |
| 覆盖 | 面板 yPercent 100 → 0，0.5 秒，power4.in |
| 上弧展开 | 0 → 10svh，0.4 秒，power4.in |
| 章节名 | 覆盖开始 0.55 秒后，opacity 0 → 1、y 0 → -50px，0.8 秒 power4.out |
| 新页面提交 | 面板完全盖住后才允许路由提交，懒加载未好时继续保持遮罩 |
| 揭幕 | 完全覆盖后至少留 0.65 秒；面板 yPercent 0 → -100，0.8 秒 power3.inOut |
| 下弧收起 | 揭幕开始 0.2 秒后，10svh → 0，0.85 秒；540px 以下为 5svh |
| 首次直达 | 直接保持满屏章节名 0.5 秒，路由落地后再揭幕 |
| 减少动态 | 短淡入、换页、短淡出，各 0.12 秒，无大面积纵向位移 |

弧线使用独立上下装饰层：容器宽 100%，内部椭圆宽 150%、高 745%；幕布本体保持矩形。弧高现在通过固定尺寸加 scaleY/yPercent 合成，视觉仍是表中的高度变化，不再每帧修改 height。章节字样以原 power4.out 采样曲线驱动浏览器原生 transform/opacity，揭幕时交回 GSAP 退出淡出。桌面与窄屏显示双语，中文和英文分层排版，避免长标题溢出

## 集成边界

- `src/components/PageCurtain.vue` 只处理画面、GSAP 时间线与取消时结清 Promise，不操作路由或全站锁
- `src/App.vue` 在 RouterView 外持有唯一幕布，通过 beforeEach / afterEach 统一处理六卡、索引、页尾、返回入口和历史导航
- `src/composables/usePageCurtain.ts` 集中保存章节名、遮罩活动状态和内容放行门禁
- `page-turn-lock` 与 `route-stage` 的 inert 由 App 持有，直到揭幕结束才释放；内容动画在揭幕开始时放行
- 六个子页移除各自重复的 PageLoader、固定深色幕与清锁定时器；原标题、肖像、Logo、视频、照片及滚动动画保留
- 卡片列表保留原放大，之后统一进入全局遮罩；首页画廊保留原聚焦、展开、历史位置与会话面包屑
- 索引在转场中禁用入口，菜单自身完成退场；不在菜单退场中途卸载组件，以免留下 Teleport 残层
- 同页 hash / query、语言切换、邮件、下载和回顶不播放整页转场；同页操作可取消尚未落地的其它目标

## 导航保护

- 沿用原有 8 秒等待提示、失败重试入口，以及懒加载失败时最多一次整页重试
- 等待与失败提示高于遮罩，能在慢请求期间操作
- 每次导航有序号，旧请求或旧动画完成后不能揭掉新导航的幕布
- 旧 `/card/02`、`/card/04` 首访以最终重定向路由揭幕，不将用户留在原地址的遮罩中
- 后退接管、同页操作取消、错误和卸载路径均清理遮罩与锁；卡片放大定时器不会覆盖更新的导航意图
