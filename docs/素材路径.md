# 公开模板素材

公开目录 `public/about/`、`public/portfolio/`、`public/internship-clean/`、`public/color-previews/`、`public/color/` 与 `src/assets/color-frames/` 只存放合成几何示例。`public/resume.pdf` 是虚构的填写模板。

`public/模板素材清单.json` 登记相对路径、像素尺寸和审核摘要。图片仍按原布局比例提供响应式候选；作品内容与文字均不作为真实履历证明。

私人原件只保存在被忽略的本机目录，开发服务不会自动读取私人媒体。禁止将这些目录、截图、旧资料或压缩包强制加入公开仓库。
