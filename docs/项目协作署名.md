# 项目协作署名

**Template Contributors · ChatGPT · Codex · DeepSeek**

本项目由维护者主导，并在制作过程中使用 AI 工具协作。依维护者意愿，在此公开记录各方的协作角色；供其他 agent 读取的对应记录位于根目录 [项目协作署名.json](../项目协作署名.json)。

| 名称 | 身份 | 协作内容与依据 |
| --- | --- | --- |
| Template Contributors | 项目维护者 | 负责需求、设计判断、内容选择、最终审核与发布决定。 |
| ChatGPT | AI 协作工具 | 辅助方案讨论、说明文档、检查与问题分析。 |
| Codex | AI 协作工具 | 辅助代码实现、重构、测试验证与发布流程。 |
| DeepSeek | AI 协作工具 | 依维护者确认，作为参与项目的工具署名；未核实到具体改动，不编造提交、文件或代码归属。 |

## GitHub 撰稿人区域

GitHub 根据提交及账户关联生成贡献者统计。默认分支中的有效提交、作者邮箱与账户的关联等会影响统计；历史改写后的显示也可能需要等待刷新，详见 [GitHub 官方贡献者说明](https://docs.github.com/en/repositories/viewing-activity-and-data-for-your-repository/viewing-a-projects-contributors)。

GitHub 支持通过 `Co-authored-by` 记录真实共同作者，但关联账户需要使用作者对应的邮箱，详见 [GitHub 官方共同署名规则](https://docs.github.com/en/pull-requests/how-tos/commit-changes/creating-a-commit-with-multiple-authors)。本记录没有为 AI 工具虚构邮箱、GitHub 账户或历史提交，因此不会自动在侧栏增加三个头像；项目主页通过 README 明确展示上述协作名单。
