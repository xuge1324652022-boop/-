## 更新演示

运行 `npm run build:cloudflare` 完成隐私与质量检查，再运行 `node scripts/准备模板演示站.mjs`。后者读取 `发布配置/模板演示站.json`，以演示站真实根域构建独立产物到忽略目录 `tmp/模板演示站/dist`，生成八个路由 HTML 和真实 404 所需的 `404.html`。运行该脚本不会上传或改变站点受众。

使用 Sites 的源码同步与发布流程，只同步 `tmp/模板演示站` 这个独立目录。发布前必须核对其中的二进制摘要与 `public/模板素材清单.json`、`发布配置/公开第三方素材.json` 一致，并扫描文本及简历内容。不得把整个本地工作区当作发布目录，也不得复用个人入口的站点编号。

发布后核对首页、八个正式路径、示例简历和媒体 Range 请求，并确认不存在路径返回 404。GitHub About 的 Website 只填写上述模板演示网址。
