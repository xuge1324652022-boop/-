# 公开模板部署与源码归档

这是静态 Vue 网站，服务器不需要持续运行 Node。重新构建时使用 package.json engines 允许的 Node 版本，当前为 22.16+ 或 24 系列。Python 交付工具要求 3.12+。

## 两份交付物

- **网站上线部署包**：site/ 只包含审核过的公开模板网页、几何示例图片、静音示例视频和空白简历；配置/nginx.conf 是服务器配置模板。
- **公开模板源码**：仅包含经过隐私门禁审核、已纳入 Git index 的源码文件；不包含 Git 历史、私人作品、真实简历、参考资料、截图、备份或账户配置。交付清单使用 sourceArchive 字段。

两份交付物均不属于私人原件备份。历史的“项目完整归档”可能含私人文件，不能作为当前公开源码包上传。旧 Release、旧包和旧提交的清理状态另见[公开内容与隐私检查](./公开内容与隐私检查.md)。

## 生成新版本

先审阅并暂存准备公开的修改，再运行：

```sh
npm ci
npm run check:privacy
python scripts/build-release.py
python scripts/verify-release.py --delivery 上线交付/YYYY-MM-DD
```

脚本拒绝 index 与工作区不同或存在未纳入版本控制的新文件，避免扫描一种内容却归档另一种内容。随后检查中文组件库、图片清单、类型和生产构建，通过素材助手生成审核快照，再生成两份 ZIP。每次使用新目录，不覆盖历史交付；同日再次生成使用 --label v2。

视频只取审核后的 dist 或 public/color 示例，同时核对公开素材 SHA-256 和媒体清单的 hash/大小。缺失、变化或未审核资源会停止交付，不能回退到作品/、media/color 或旧站私人媒体。

交付目录保留审核快照、未压缩部署文件、文件级 SHA-256 清单及 ZIP 的 SHA-256/CRC。verify-release.py 还会核对 sourceArchive、私人目录隔离和动态媒体清单，不写死视频数量。

## 上传到服务器

1. 解压网站上线部署包，将 site/ 内容放入 Nginx root 指向的专用目录，根下应直接包含 index.html、assets/、color/ 等。
2. 将配置/nginx.conf 纳入服务器的 http 配置范围，按实际目录和域名调整 root 与 server_name；正常载入 mime.types。
3. 执行 nginx -t，通过后再重载服务器配置。本项目的本地检查不能代替服务器实机验收。
4. 使用服务器已有的证书管理方式配置 HTTPS。保留旧版部署目录，以便切换目录回滚。

只上传部署包中的网站内容，不将源码 ZIP、审核记录或本机资料放入公开网站根目录。入口 HTML 不长缓存，带哈希的 assets 可长期缓存。

## 上线检查

- 正式路由直接打开、刷新和浏览器前后退均正常；旧 card 路径进入对应正式路由，未知页面与缺失资源返回真实 404。
- 按媒体清单检查视频播放、HEAD、206 Range 和越界 416，不能用首页 HTML 代替缺失媒体。
- 检查首页开场、章节转场、手机菜单、图片查看器、语言和减少动态效果；真实 iOS/Android/微信环境仍需对应设备验收。
- 简历下载的是空白示例，页面姓名、履历和联系方式均是虚构占位。若自行替换资料，应重新审核公开范围、素材清单、源码副本及生成的包。
