# 手机浏览器兼容修复

日期：2026-10-19。针对微信内置浏览器及手机 Safari、安卓 Chrome/WebView 的兼容路径，保留现有作品与正常尺寸下的动画；不变更域名或付费方案。

## 本轮修复

| 问题 | 处理 |
| --- | --- |
| 390×600短可见区域，人物照片遮挡介绍链接 | 紧凑竖屏使用已有自然流分支；照片保持彩色4:3。普通竖屏仍保留sticky空间动画。 |
| 手机无法悬停，索引入口静置后消失 | 无悬停/粗指针设备保持索引可见；桌面保留原闲置动画。索引关闭、查看器箭头与相关海报控件提供44px点击范围。 |
| iOS/旧微信弹层边缘滚动可能带动背景 | 索引、看图与转场共用触摸守卫；只阻断无法被内部容器消费的单指滚动。保留缩略条滚动、双指缩放及放大后的视口平移，卸载释放监听。 |
| 微信拒绝视频自动播放后，没有可用操作 | 拒播后显示“播放影像”，点击处理栈内调用play；区分中断和权限错误，防止旧异步请求改变新状态。 |
| 长调色页积累播放器与后台播放 | 远离预热范围的成片释放src/缓冲/循环动画；菜单覆盖、隐藏、离屏时暂停，恢复可见后按原条件播放。 |
| 调色触摸轨迹跨手势累计；首页双指拖拽跳位 | 主指、抬手、取消和缩放分别处理，舞台外不生成预览；第二根手指取消旧首页拖动。 |
| 擦入动画中点切换inert导致点开的作品与画面不同 | 让实际裁切区域负责命中；当前作品管理键盘焦点，完全被覆盖的章及其子层同步隐藏。 |
| 旧浏览器不识别svh，舞台或照片尺寸失效 | 用稳定视口变量渐进增强vh→svh，弹层使用vh→dvh；地址栏变化不重设滚动动画行程。 |
| 不支持cqw时空间海报字体/结构失效 | 只在能力缺失时展示完整原稿自然流，保留查看器；支持浏览器保持原空间效果。 |
| 部分Safari/WebView缺少现代API字段 | 删除运行中的Array.at调用；ResizeObserver缺少borderBoxSize时读contentRect；原生元素动画缺失时用同时间线GSAP退路。 |
| 横竖屏文本放大、刘海/底部安全区 | 固定自动文本缩放比例；索引和查看器避让安全区。桌面悬停样式不再作为触屏操作反馈。 |

Vite输出语法显式设置为Chrome94、Safari15、iOS15目标，避免沿用Vite8较高的默认目标。这是编译语法目标，不表示这些历史版本及所有手机内核均已完成实机验收，也不自动提供DOM/媒体API。

## 验证

已通过类型检查与生产构建；定向回归包括：

- `scripts/verify-mobile-overlays.mjs`：19项弹层/索引触摸边界。
- `scripts/verify-wechat-color-media.mjs`：5组拒播重试、异步取消、资源释放、多指及轨迹边界。
- `scripts/verify-about-mobile-runtime.mjs`：窄屏蓝球边界、紧凑屏自然流与普通屏动画分支。
- `scripts/verify-mobile-artwork.mjs`：实际擦入函数、倒滚、隐藏子层及容器单位回退。
- 原导航/开场生命周期、摄影章节和海报数学回归。

本地受支持浏览器已观察：390×600介绍与照片分隔40px；横屏自然流后返回390×844恢复sticky，未遗留旧尺寸。320×568索引六入口与44px关闭按钮可用，打开时不滚背景，关闭后恢复原位置和滚动，切换摄影后无残留菜单锁。摄影擦入约25%点击新图、约74%点击旧图剩余区域，打开对应大图；缩略条末张可见，关闭回到触发按钮。海报约25%新图及过中点旧图区域点击正确。

调色页正文视频在测试浏览器中实际播放并推进时间；索引打开后暂停，滚远后前部视频src已卸载；没有自然触发拒播，按钮路径由真实函数回归覆盖，不能表述为微信真机播放成功。

浏览器记录与截图保存在 `outputs/wechat-mobile-audit-2026-10-19/`。本轮并未持有iPhone Safari、安卓或微信真机，不能将视口检查与代码回归等同于跨内核实机检查；微信系统全屏策略、手势返回和真实低端手机表现仍需复核。网络连通问题独立于本次前端修复。

最终宽度巡检：320×568与390×844各检查关于我、剪辑、调色、新闻、海报、摄影，共12组；全部scrollWidth等于clientWidth、索引44×44px，未见已加载损坏图片。测试平台为IAB，未更改UA或触摸能力；受支持接口未提供UA，未猜测浏览器版本。读取到的console warn/error为空。
