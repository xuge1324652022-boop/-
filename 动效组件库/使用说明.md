# 动效源码包（中文组件库）

这是求职者应聘展示模板网站的配套源码库。38 种效果分别归档，文件夹、说明、解析及源码副本均使用中文名称，方便人和其他 agent 查找、理解与迁移。

## 目录与读取协议

```text
动效组件库/
├── 使用说明.md
├── 组件索引.json                  # 分类、标签、入口、覆盖情况及源码摘要
├── 解析格式规范.json              # 定义与效果解析文件的 JSON Schema
├── 命名映射.json                  # 稳定效果 ID、原始路径与中文名称的明确映射
├── 效果定义/<中文效果名>.json       # 手写解析，维护入口
└── 效果组件/<中文效果名>/
    ├── 效果介绍与解析.json         # 解析、依赖版本、来源与原文/副本摘要
    ├── 使用说明.md                # 人类阅读入口与接入步骤
    ├── 源码/项目源码/...           # 中文入口、传递源码依赖与全局样式
    └── 集成示例/项目源码/...       # 页面与路由调用方的参考快照，按需存在
```

建议 agent 依次读取：`组件索引.json` → 目标 `效果介绍与解析.json` → `bundle.entryFiles` 对应的中文文件 → `sources` 中的依赖 → `集成示例/` → 验证说明。`relatedEffects` 使用稳定的英文 ID 关联其他效果，可通过索引或命名映射找到中文目录。`sourceSections` 定位原源码标识符，`mechanism` 描述触发、阶段、状态和属性所有权；`lifecycle.knownLimitations` 记录当前实现的边界。

解析中的 `entryFiles`、`integrationFiles`、`sourceSections.file` 与 `sources.original` 保留原仓库维护路径。实际中文副本路径见 `bundle.entryFiles`、`sources.path`，这些路径相对于每个效果文件夹。英文 JSON 字段、效果 ID、代码标识符、CSS 类名和 npm 命令保持原有协议；`.gitattributes` 保留 Git 要求的标准文件名。

`源码/` 包含入口的完整本地导入闭包：组件、类型、数据、CSS、JSON、全局样式和直接导入的小型图片。生成器按 `命名映射.json` 改写本地 import、动态 import、导出路径、Vue 外部样式引用及 CSS 导入，保持代码逻辑与外部资源地址。重复依赖在各效果包中各自保存，便于单独阅读。`集成示例/` 只解释原页面接线，不包含完整依赖，不作为独立构建入口。

## 效果范围

- 全站弧形幕布、首页黄色撕裂开场、六卡画廊聚焦与返回、叠牌放大和索引弹层。
- 六张卡片各自的入场、指针视差、显影、新闻循环及公共生命周期。
- 双语逐行文字、人物首屏与照片场景、页面标题及通用滚动入场。
- 摄影章节擦除与选片、海报叠层、碎片显影、空间构图、色带与色彩章节。
- 调色视频轨迹与首屏闸门、视频循环接缝淡化、大图查看器、动作光标和磁吸联系球。
- 字号拟合、布局预热与刷新、平滑滚动等支持代码；未在生产入口使用的兼容效果标为 `legacy`。

实现包含 GSAP、ScrollTrigger、SplitText、Web Animations、CSS 和原生 RAF。每份解析标注实际机制；所有直接导入 GSAP 的源码都有明确说明，覆盖清单见索引的 `gsapCoverage`。

## 迁移与运行

这是 Vue 3 浏览器应用的源码迁移包，可通过 GitHub Packages 安装为 `@xuge1324652022-boop/animation-source-package` 源码资料包，供读取或复制代码；不提供直接调用动效的通用运行时 API。安装方法见 [安装与读取说明](../README.md)；仓库中的完整配置见 `发布配置/源码资料包/安装与读取说明.md`。先检查 JSON 的 `integration`、`accessibility`、`lifecycle` 和 `npmDependencies`，保留实际 DOM 分层与动画属性所有权，再适配目标项目。

1. 安装兼容的 Vue、GSAP 等依赖，按需注册插件；锁定版本见 `npmDependencies`。
2. 保留 `源码/项目源码/` 中相关目录结构，按 `bundle.entryFiles` 选择中文组件或组合函数，并接入全局样式。
3. 根据 `集成示例/` 与解析连接父页面门闩、路由、数据和事件；跨页状态应共享模块实例。
4. 提供 `integration.assets` 中引用的公开图片、视频、简历、字体与正确 URL。直接 import 的小图已包含；外部媒体和 `node_modules` 不复制。
5. 按 `verification` 验证遮挡、慢加载与取消、反向滚动、手机、键盘和减少动态分支。

个别源码在模块求值时读取 `window`，迁移到 SSR 项目需设置客户端边界。解析保留现状与已知限制，不将现有实现宣称为已完善的通用组件。

## 维护与一致性

应用维护源在仓库根目录 `src/`；解析维护源是 `效果定义/`，中文命名维护源是 `命名映射.json`。生成的 `效果组件/` 与 `组件索引.json` 不应直接编辑。

```sh
npm run build:motion
npm run check:motion
npm run typecheck
npm run test:deployment
npm run build
```

生成器位于 `scripts/生成动效组件库.mjs`。原文以 UTF-8/LF 规范化，`sources.originalSha256` 和 `originalBytes` 记录规范化原文；`sha256` 和 `bytes` 记录本地导入改写后的副本。图片保留原始字节；原文与副本的摘要分别可验证，应用根目录源码不参与中文重命名。

生成器验证 JSON、命名唯一性、中文文件路径、依赖闭包、实际版本、GSAP 覆盖及原文/副本摘要；拒绝未知路径、符号链接、缺失导入和未声明依赖。旧生成文件仅在上一索引证明归属且内容未改动时逐个移除，随后只清理空目录；未知用户文件会令生成停止。

新增效果时参考 `效果定义/`，使用 `解析格式规范.json`，并在 `命名映射.json` 中登记稳定效果 ID 与中文名。新增源码依赖时同步登记中文路径。
