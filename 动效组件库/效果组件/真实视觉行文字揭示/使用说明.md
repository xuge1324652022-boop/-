# 真实视觉行文字揭示

共享双语介绍组件，按最终排版的真实行切分。标题从行遮罩底部上移，正文用段落与行的独立淡入位移。页面门禁、视口预热与播放触发相互分离；字体、语言和排版变化后延续已播放进度，避免重读内容再次隐藏。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 在 Vue 页面导入 ReferenceIntroduction.vue，传入 string 或 {zh,en} 文本。
2. 页面使用 provide(referenceIntroductionGate, readonlyRef) 关联加载幕和路由状态；不提供时默认放行。
3. 短标题选择 treatment=title；常规介绍保留 paragraph。逐段阅读可选择 revealBy=paragraph。
4. 父空间场景可显式传 reveal；常规文档流保留未定义以使用滚动触发。复制时同时保留 motionLayout 和 viewportEntrance 依赖。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。

## 维护

修改根目录 `src/`、`动效组件库/效果定义/真实视觉行文字揭示.json` 或 [命名映射](../../命名映射.json)，再运行 `npm run build:motion`。用 `npm run check:motion` 检查 JSON、中文导入闭包及原文/副本哈希。
