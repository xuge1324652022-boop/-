# 调色首屏滚动闸门与进度阻尼

调色页首屏先把滚轮或触屏纵向位移喂给底部白条，累计一趟首屏高度后一次性放行正文滚动；显示值由原生 RAF 指数收敛。本效果没有独立组件或独立 GSAP 时间轴，而是 ColorView 页面内逻辑，并与现有 useSmoothScroll 配合。该文件还含文字和正文媒体生命周期，文档明确保留这些集成边界。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 复用 ColorView 内 introRef、进度 ref/computed、feedGate、barFrame 与触摸监听，保留进度条模板的 --p 和 ARIA。
2. 传 feedGate 给现有 useSmoothScroll；不要再注册另一个 wheel 消费器。
3. 移植 gate 时单独识别同文件的媒体逻辑：300px 预热、25% 可见播放、幕布/索引暂停、离开预热释放 src，以及视频循环淡化均是正文媒体能力。
4. 保留 covered 与 routeCurtainActive 门禁；初始文字观察器需等待幕布不再覆盖再建立。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。
