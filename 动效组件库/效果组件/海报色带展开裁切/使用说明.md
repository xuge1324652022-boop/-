# 海报色带展开与裁切

海报页的色带舞台按滚动段或按钮选择展开作品，以一个 GSAP 标量补间同时更新所有色带权重，保证权重和为一。内部画幅保持固定尺寸，CSS 按权重控制色带占比、遮罩和面板透明度，避免图像随展开被挤压。短视口和减少动态切换为普通流手动阅读。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 传固定序列的 VisualAsset items 与 lang，确保每项 id 唯一。
2. 监听 open(index,trigger) 并用原 items 索引打开大图；可选监听 change 与页面同步语义选择。
3. 保留 prepareMotionLayout/requestMotionLayoutRefresh 调度，避免前序 sticky 段改变高度后 origin 失真。
4. 主题内容位于 tones 与 posterPage 的系列标题/说明，移植到新素材时更新对应数据。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。

## 维护

修改根目录 `src/`、`动效组件库/效果定义/海报色带展开裁切.json` 或 [命名映射](../../命名映射.json)，再运行 `npm run build:motion`。用 `npm run check:motion` 检查 JSON、中文导入闭包及原文/副本哈希。

状态：`active`。关联效果：[海报色彩章节擦入](../海报色彩章节擦入/效果介绍与解析.json)、[完整作品查看器遮罩](../完整作品查看器遮罩/效果介绍与解析.json)、[局部动作文字光标](../局部动作文字光标/效果介绍与解析.json)。
