# 调色卡五层指针视差

巨型 COLOR、色条、胶片框、曲线与色轮组成静止调色构图，五层只按指针位移。卡面不携带真实调色视频、不自动转色轮、不随指针改色；真实作品位于独立 /color 页面。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 通过注册表 createCardAnimation(index) 创建新实例，并提供 CardVisual 中对应的 cv-* DOM/CSS。
2. mount(host) 后按宿主可见性调用 play/pause；聚焦章节时 restart()，active 状态调用 setActive。
3. 通过 destroy() 撤销实例；不能仅删除宿主 DOM。
4. 保持 CHAPTERS 与 CardVisual.index/kind 的顺序一致；本效果类不自行创建卡面 DOM。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。

## 维护

修改根目录 `src/`、`动效组件库/效果定义/调色卡五层视差.json` 或 [命名映射](../../命名映射.json)，再运行 `npm run build:motion`。用 `npm run check:motion` 检查 JSON、中文导入闭包及原文/副本哈希。

状态：`active`。关联效果：[六卡空间画廊聚焦](../六卡空间画廊聚焦/效果介绍与解析.json)、[关于我卡扫描遮罩](../关于我卡扫描遮罩/效果介绍与解析.json)、[新闻卡擦开与循环](../新闻卡擦开与循环/效果介绍与解析.json)。
