# 摄影原片到编辑版面的固定舞台擦除

将相同比例的摄影原片与其编辑封面叠进同一取景框，滚动到舞台后由左向右擦出封面，并同步交叉淡化图注与推进细线。擦满后保留阅读行程再解除pin；向上滚可原路退回。窄屏、矮屏或减少动态保留两张完整静态对照。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 在页面渲染EditorialPair并传相同比例的两张VisualAsset，设置morph；当前海报页为16:9原片与16:9版面。
2. 加载幕撤掉并解除滚动锁后，针对页面root调用setupEditorialScroll；若已使用setupAboutReveal，该句柄已经自动创建editorial分支，不要重复调用。
3. 监听open(item,trigger)接入作品查看器。
4. 页面卸载调用dispose；如果由setupAboutReveal管理，用其dispose按先pin、后其他context的顺序清理。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。
