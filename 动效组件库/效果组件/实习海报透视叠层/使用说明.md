# 实习海报透视收拢与逐页覆盖

海报从透视空间推入并收拢为正面纸面，随后逐张从上向下覆盖。每个阶段、当前页、可点击可见区域和按钮跳转都由同一个以舞台高度为单位的数学行程决定。运动由scrollY/rAF直接写样式，ScrollTrigger只参与全站布局刷新通知。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 在海报页传精选VisualAsset数组与lang，监听open接入完整作品查看器。
2. 保留internshipStackMotion纯函数和完整sticky舞台结构；根高度由measure按1+stackTravel计算。
3. 保留共享motionLayout队列及ScrollTrigger refresh监听，避免上方双语段落重排后按钮按旧起点跳转。
4. 更改数量时同步核对projectNames默认三个产品名称和数据顺序；按钮跳转必须继续使用stackPagePosition。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。
