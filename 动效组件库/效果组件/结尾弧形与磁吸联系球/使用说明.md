# 结尾弧形衔接与磁吸联系球

关于页页脚把滚动驱动的弧形收束、内容/箭头/联系位置位移，与精细鼠标驱动的磁吸球和文字分层组合。ScrollTrigger scrub 负责进入页脚的连续衔接，quickTo 负责局部磁吸，离开后弹性归位；邮件、简历和作品导航仍是原生入口。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 在关于页结尾传 lang 挂载 ContactEnd，提供页面主题 --ab-bg。
2. 复用 CONTACT 与 FACTS 数据，替换求职者邮箱、简历、角色和可用状态。
3. 保留 curve/content/contactPosition/magnet/orb/orbText 的层级，分别承接滚动、命中和磁吸。
4. 保留 prepareMotionLayout 与临近视口 observer，避免远端页脚挤占首屏动画准备。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。

## 维护

修改根目录 `src/`、`动效组件库/效果定义/结尾弧形与磁吸联系球.json` 或 [命名映射](../../命名映射.json)，再运行 `npm run build:motion`。用 `npm run check:motion` 检查 JSON、中文导入闭包及原文/副本哈希。

状态：`active`。关联效果：[局部动作文字光标](../局部动作文字光标/效果介绍与解析.json)、[全站弧形路由幕布](../全站弧形路由幕布/效果介绍与解析.json)。
