# 子页作品索引覆盖菜单

跨子页常驻的作品索引菜单。右上按钮因滚动唤醒、桌面闲置隐藏；面板 Teleport 到 body，背景 inert 并独占滚动锁。GSAP 控制背景淡入和章节行从裁切区上移，点击链接交接全局路由导航。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 按 App 当前方式跨六个子页常驻，保留 Teleport 与 #app 根节点约定。
2. 以 CHAPTERS 生成顺序并用 jumpPathFor 导航。
3. 保留 source 判断：query.from=cards 或旧 /card/* 的默认来源决定返回 /cards，其余返回 /。
4. 在宿主样式提供 --stable-viewport-height / --dynamic-viewport-height；接入 overlayTouchGuard。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。

## 维护

修改根目录 `src/`、`动效组件库/效果定义/子页作品索引覆盖菜单.json` 或 [命名映射](../../命名映射.json)，再运行 `npm run build:motion`。用 `npm run check:motion` 检查 JSON、中文导入闭包及原文/副本哈希。

状态：`active`。关联效果：[全站弧形路由幕布](../全站弧形路由幕布/效果介绍与解析.json)、[六卡空间画廊聚焦](../六卡空间画廊聚焦/效果介绍与解析.json)。
