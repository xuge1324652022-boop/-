# 作品子页大标题揭示

摄影、海报、剪辑/新闻三类宿主使用同一揭幕门闩，先播放标题的上移渐显，再放行介绍与正文入场；本目录保留各宿主完整实现供迁移对照。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 按目标页面选择一个宿主，抽取playIntro和covered门闩并保持参数。
2. 在根页面provide(referenceIntroductionGate)，标题结束后放行正文。
3. 迁移完整页面时同步数据、查看器和滚动样式；仅复用标题时删除无关页面块并自行重新验证。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。

## 维护

修改根目录 `src/`、`动效组件库/效果定义/作品子页大标题揭示.json` 或 [命名映射](../../命名映射.json)，再运行 `npm run build:motion`。用 `npm run check:motion` 检查 JSON、中文导入闭包及原文/副本哈希。

状态：`active`。关联效果：[全站弧形路由幕布](../全站弧形路由幕布/效果介绍与解析.json)、[真实视觉行文字揭示](../真实视觉行文字揭示/效果介绍与解析.json)、[数据标记滚动揭示](../数据标记滚动揭示/效果介绍与解析.json)、[大标题字号拟合](../大标题字号拟合/效果介绍与解析.json)。
