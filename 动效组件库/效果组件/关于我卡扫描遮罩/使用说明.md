# 关于我卡视差与 DEMO 扫描遮罩

首页 ABOUT 卡由三层空间构图、DEMO 几何 SVG 扫描线和聚焦落定组成。AboutAnimation 只为 card-visual 宿主做轻微淡入/缩放/位移；真实指针视差在 AboutExperience 独立实现，扫描线通过 SVG mask 只在几何结构内部显示。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 通过 CardVisual 的 about 分支挂载 AboutExperience；保留 aboutExperience.css 导入及 TemplateMark 子组件。
2. 若独立迁移 createAboutExperience，提供含 type/logo/info 对应 class 的 host，并在卸载调用返回 handle.destroy。
3. 聚焦落定与视差是不同入口：需要聚焦落定时再用 AboutAnimation，不要把旧字母逻辑加回类。
4. 替换求职者姓名、角色和年份时编辑 AboutExperience 的实际文案；巨型文字和 logo 默认 aria-hidden。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。
