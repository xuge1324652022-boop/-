# 数据标记滚动揭示控制器

以 data 属性集中创建单元素、分组错峰、章节线条和成果数字入场，并保留聊天气泡的双轴展开分支。通用揭示和聊天使用两个 GSAP context，编辑对照另有独立 matchMedia 句柄；当前直接集成在海报页与摄影页。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 页面加载幕撤掉并解除滚动锁后，用真实页面根调用 setupAboutReveal。
2. 元素添加 data-reveal；组容器添加 data-reveal-stagger；在近祖先 data-motion 指定 rise/slide/wipe/scale/fade。
3. 成果数字同时绑定 data-count 与当前语言原文 data-count-value；换语言若存在聊天分支，在 DOM 更新后调用 rebuildChat。
4. 页面卸载调用返回句柄 dispose；editorial 已由句柄统一管理，不要再对同一 root 重复 setupEditorialScroll。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。

## 维护

修改根目录 `src/`、`动效组件库/效果定义/数据标记滚动揭示.json` 或 [命名映射](../../命名映射.json)，再运行 `npm run build:motion`。用 `npm run check:motion` 检查 JSON、中文导入闭包及原文/副本哈希。
