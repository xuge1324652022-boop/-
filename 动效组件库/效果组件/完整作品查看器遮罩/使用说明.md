# 完整作品查看器遮罩

摄影与海报共用的大图弹层，通过 Teleport 脱离页面裁切，以 CSS opacity 入场、contain 保持原构图。模块级 composable 持有唯一作品序列和索引，组件处理焦点圈定、锁滚与输入；关闭后可取消地恢复原位置和触发焦点。该效果未使用 GSAP。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 页面取得 useVisualViewer 单例，以 active 条件渲染一份 VisualViewer。
2. 绑定 item、items=list、index、lang，并把 close/step/goTo 事件连接到同一 composable 的方法。
3. 作品按钮将 currentTarget 作为 trigger 传入 open/openAt。
4. 每个使用页面 onBeforeUnmount 调用 reset，避免单例状态残留；保留全站 html.no-scroll 样式。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。
