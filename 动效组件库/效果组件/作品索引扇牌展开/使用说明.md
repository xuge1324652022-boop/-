# 作品索引扇牌展开

/cards 的六张扇形牌堆使用每卡独立 CSS 变量配置缩放、旋转、缓动与原点。点击或键盘激活先展开当前卡，再导航至对应子页并交由全局路由幕布覆盖；该展开本身没有 GSAP。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 保留配置数组作为独立动效参数的唯一来源。
2. 使用 event.currentTarget 定位目标卡，不依赖 v-for ref 数组顺序。
3. 接入统一 jumpPathFor 映射与 App/PageCurtain；不要拼旧 /card/NN。
4. 保留 query.from=cards，让子页返回入口指向作品索引。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。

## 维护

修改根目录 `src/`、`动效组件库/效果定义/作品索引扇牌展开.json` 或 [命名映射](../../命名映射.json)，再运行 `npm run build:motion`。用 `npm run check:motion` 检查 JSON、中文导入闭包及原文/副本哈希。

状态：`active`。关联效果：[全站弧形路由幕布](../全站弧形路由幕布/效果介绍与解析.json)、[六卡空间画廊聚焦](../六卡空间画廊聚焦/效果介绍与解析.json)。
