# 黄色开场双幕撕裂

首页两份完全相同的黄底版面先重叠，显示视觉百分比和文字序列，再用 clipPath 各保留上下半屏，向相反方向移走，将画面同步交接给六卡画廊。百分比不是资源下载进度。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 保留双份相同模板及两层的 z-index 9999/9998。
2. GalleryView 在 complete 事件时让 v-if 卸载；不要手动 remove Vue 模板节点。
3. 同时监听组件 complete 和窗口 preloader-complete 的各自职责：前者收起幕布，后者通知画廊和静态 boot-splash。
4. 先在黄幕下挂载 ThreeHome，再在完成事件启动运动。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。

## 维护

修改根目录 `src/`、`动效组件库/效果定义/黄色开场双幕撕裂.json` 或 [命名映射](../../命名映射.json)，再运行 `npm run build:motion`。用 `npm run check:motion` 检查 JSON、中文导入闭包及原文/副本哈希。

状态：`active`。关联效果：[六卡空间画廊聚焦](../六卡空间画廊聚焦/效果介绍与解析.json)、[全站弧形路由幕布](../全站弧形路由幕布/效果介绍与解析.json)。
