# 摄影双列章节与纵向遮罩接力

摄影页按色彩分章，每章将横图与竖图分为两个等高窗口，滚动时同一位置推进两列照片。横列从底向上揭开、竖列从顶向下揭开；一章末张完成并停留后，下一章整屏从下方揭入。该效果使用scrollY、requestAnimationFrame和纯数学日程，不由GSAP时间线驱动。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 从PhotoView模式页面传非空PhotoSet[]，每章保留palette与VisualAsset数组；源项目先通过assertPhotoSets检查数据。
2. 保留sticky舞台、章、双列lane、slot和card的DOM层次；横图窗口3:2、竖图窗口2:3。
3. 监听open(item,trigger)接入页面查看器；需要查看完整原构图时使用该事件，展示窗内横图通常以cover填满。
4. 同步复制photoStory、usePhotoDrag及数据类型；该组件没有外部GSAP初始化句柄。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。
