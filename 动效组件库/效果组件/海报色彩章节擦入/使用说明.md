# 海报色彩章节双向擦入

按稳定素材 id 将海报划为四个色彩章节，以原生 sticky 舞台和滚动进度叠层擦入：换组由下向上揭示，同组由右向左揭示。GSAP CustomEase 只映射进度，遮罩由 RAF 单一写入者控制，并只保留底图和正在揭开的顶图可见。减少动态或短视口时逐张普通流展示。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 传入含已知稳定 id 的 VisualAsset 列表与 lang，更新 groups 可更换主题与素材匹配规则。
2. 监听 open(originalIndex,trigger)，以原列表传给统一 useVisualViewer.openAt。
3. 保留布局队列与 ScrollTrigger.refresh 监听，使前序章节高度变化后 origin 正确。
4. 保留静态 CSS 与 prefers-reduced-motion/短视口响应逻辑；不要只截取 render 而缺少 reset 样式。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。

## 维护

修改根目录 `src/`、`动效组件库/效果定义/海报色彩章节擦入.json` 或 [命名映射](../../命名映射.json)，再运行 `npm run build:motion`。用 `npm run check:motion` 检查 JSON、中文导入闭包及原文/副本哈希。
