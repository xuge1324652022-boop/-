# 大标题字号拟合

按容器真实宽度和当前字体度量拟合单行大标题，避免遮罩与视口裁切隐藏末尾字母；使用原生Range和观察器，不由GSAP驱动。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 为标题创建HTMLElement ref，在setup调用useFitText(ref,{min,max})。
2. 确保clientWidth代表文字可用宽度，左右留白放在父容器。
3. 需要时调用返回fit；保留CSS字号作为脚本初始化前基线。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。

## 维护

修改根目录 `src/`、`动效组件库/效果定义/大标题字号拟合.json` 或 [命名映射](../../命名映射.json)，再运行 `npm run build:motion`。用 `npm run check:motion` 检查 JSON、中文导入闭包及原文/副本哈希。

状态：`active`。关联效果：[作品子页大标题揭示](../作品子页大标题揭示/效果介绍与解析.json)、[真实视觉行文字揭示](../真实视觉行文字揭示/效果介绍与解析.json)。
