# 全站弧形路由幕布

用上下椭圆帽和整屏位移实现跨路由覆盖、停留与揭幕。PageCurtain只承担视觉动作；useRouteCurtainNavigation显式接收router与幕布引用，等待路由和首轮布局、控制门禁及处理异常。App保留渲染，首访子页从已覆盖状态起步。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 在应用顶层常驻一个 PageCurtain，用 active/title props 连接全局状态。
2. 复用 useRouteCurtainNavigation({router, curtain}) 的 coverRoute/revealRoute 的守卫顺序；不要把 App/router 当独立视觉组件的递归入口。
3. 保留 routeCurtainBlocked 对子组件入场的门禁，routeCurtainActive 对输入、媒体和索引的门禁。
4. 保证全局 viewport CSS 变量与 overlayTouchGuard 可用；迁移时按宿主应用重接异常恢复。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。
