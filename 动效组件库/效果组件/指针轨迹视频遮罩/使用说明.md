# 指针轨迹视频遮罩预览

调色页首屏沿主指针轨迹弹出轻量视频：固定位置外框、polygon 揭示层和缩放内容层分工，最多保留五个预览；离场或被遮挡时依次缩回并释放播放器。标题另用 quickTo 轻微跟随。这是 Vue 页面中的组合效果，尚未封装为独立包。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 在具有明确宽高和裁切边界的首屏容器内挂载 ColorWave。
2. 传 clips；通过默认 slot 提供标题，页面负责标题字号与逐行遮罩。
3. 把幕布、索引等覆盖状态合并到 active；不要只依赖 IntersectionObserver 判断可用性。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。

## 维护

修改根目录 `src/`、`动效组件库/效果定义/指针轨迹视频遮罩.json` 或 [命名映射](../../命名映射.json)，再运行 `npm run build:motion`。用 `npm run check:motion` 检查 JSON、中文导入闭包及原文/副本哈希。
