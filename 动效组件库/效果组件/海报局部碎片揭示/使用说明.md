# 海报局部碎片遮罩揭示

用归一化矩形选出海报标题与图形区域，短暂在完整底图上挖出对应区域，再由复用同一张图片的裁片完成运动。MotionCard负责普通文档流自动触发与手动重播，AnimatedArtwork接受父空间场景的revealed/completed信号；两者共享同一片段时间线，完成后恢复完整原图消除拼接细缝。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 普通海报使用InternshipMotionCard(item,lang,page,total)，监听open接入页面查看器；可通过注入referenceIntroductionGate等待页面揭幕。
2. 空间纸面使用InternshipAnimatedArtwork(item,lang,revealed,completed)，由父级传入首次可见与落位完成信号。
3. 复制共享internshipArtworkMotion与internshipPosterMotion矩形配置；不同作品须按完整原图重新标定归一化片段。
4. 保留唯一maskId、完整底图与每片内部复用整图的结构；不要把图片拉伸成片段尺寸。
5. 不要把父纸张的滚动入场和内部碎片时间线合并成同一个可逆进度，首次阅读记忆由调用组件负责。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。
