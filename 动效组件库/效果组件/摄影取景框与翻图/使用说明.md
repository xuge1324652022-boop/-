# 摄影取景框展开、翻图与指针视差

保留原图比例的摄影展示舞台，整合可选宽屏滚动展开、左右裁切翻图、横拖切换和轻微鼠标视差。frame、surface、track和item分层分别承接滚动裁切、指针倾斜、拖动反馈和切图，避免同一transform被多个控制器争用。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 导入PhotoRunway，提供非空readonly VisualAsset[]与lang；About页BeyondWork以compact使用，当前实例不安装滚动展开。
2. 监听open(item,trigger)接入页面查看器与关闭后焦点还原；change(item)可同步作品说明。
3. 需要长sticky展开时不传compact，并保留完整CSS与父页面横向溢出裁切。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。

## 维护

修改根目录 `src/`、`动效组件库/效果定义/摄影取景框与翻图.json` 或 [命名映射](../../命名映射.json)，再运行 `npm run build:motion`。用 `npm run check:motion` 检查 JSON、中文导入闭包及原文/副本哈希。

状态：`active`。关联效果：[摄影双列章节遮罩](../摄影双列章节遮罩/效果介绍与解析.json)、[数据标记滚动揭示](../数据标记滚动揭示/效果介绍与解析.json)。
