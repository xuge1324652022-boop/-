# 历史指针 SVG 绘线

按真实指针历史采样生成多笔 SVG 二次贝塞尔路径，以时间淘汰旧点，尾部随轨迹老化自然消退。源码保留 createPointerTrail 工厂，但当前 src 中没有调用者，因此属于可供参考的历史实现，不代表网站正在运行的效果。未使用 GSAP。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 当前没有运行中的宿主；如需重新启用，创建具有明确坐标尺寸的 host 与覆盖 SVG/path。
2. 调用 createPointerTrail(host,svg,path,onDraw,onRest)，由宿主在入场结束且允许动态时 enable(true)。
3. 宿主负责 reduced-motion、页面可见性和 viewport/覆盖层门禁；停用时 enable(false)，卸载时 destroy。
4. 保留 host 覆盖层的 pointer-events 策略与完整 CSS 描边；不要将历史固定开场曲线误当本算法输出。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。

## 维护

修改根目录 `src/`、`动效组件库/效果定义/历史指针矢量绘线.json` 或 [命名映射](../../命名映射.json)，再运行 `npm run build:motion`。用 `npm run check:motion` 检查 JSON、中文导入闭包及原文/副本哈希。
