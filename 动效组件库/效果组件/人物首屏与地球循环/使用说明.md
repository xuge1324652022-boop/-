# 人物页首屏上移与地球循环

双语人物标题与地球轨道共同上移入场；GSAP负责一次性位移，CSS负责可暂停的装饰循环，页面active门闩决定何时可见。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 在Vue浏览器页面中挂载AboutHero并传入active和lang。
2. 从路由揭幕门闩派生active，避免在遮罩后提前演完。
3. 保留标题、轨道与地球子层结构及共享纸色色板。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。

## 维护

修改根目录 `src/`、`动效组件库/效果定义/人物首屏与地球循环.json` 或 [命名映射](../../命名映射.json)，再运行 `npm run build:motion`。用 `npm run check:motion` 检查 JSON、中文导入闭包及原文/副本哈希。

状态：`active`。关联效果：[全站弧形路由幕布](../全站弧形路由幕布/效果介绍与解析.json)、[动效布局刷新调度](../动效布局刷新调度/效果介绍与解析.json)、[关于我卡扫描遮罩](../关于我卡扫描遮罩/效果介绍与解析.json)。
