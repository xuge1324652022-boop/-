# 循环视频接缝淡化

监听 HTMLVideoElement 的播放时间，在接近片尾时将 video 自身淡至透明，浏览器 loop 回绕后再淡回；暂停立即恢复不透明，避免遮挡或离屏中断留下半透明画面。调用方负责静音、循环、可见性与减少动态策略。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 确认目标 video 已设置 muted、loop，并由外层生命周期决定播放权限。
2. 调用 attachLoopFade(video, fadeSeconds?)，保存返回的 cleanup。
3. 减少动态时不要挂载此效果；释放 video src、卸载或停用功能时执行 cleanup。
4. 为 video 留独占 opacity，把滚动淡入和播放器显示放到外层容器。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。
