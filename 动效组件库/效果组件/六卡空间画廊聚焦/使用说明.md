# 六卡空间画廊与全屏聚焦

以 CSS 3D 正交环承载六个求职作品方向。几何由纯函数计算，宿主统一渲染，GSAP 只插值 entrance、orbit 与 focus；章节转场单独只推进 focus，让选中卡铺满视口、其余卡原地淡出。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 将 ThreeHome 和数学层/转场层配套使用，按 CHAPTERS 维护六卡顺序。
2. 传入当前首页进入来源和 Preloader 状态；后退恢复传 restoreIndex 0..5。
3. 若只迁移 createChapterTransition，TransitionHost.state 必须与宿主每帧读的对象同一引用，并提供 render、完成回调。
4. 保留 card-position→card-drift→card-plane→CardVisual 分层。
5. 跨页跳转仍交给 App/PageCurtain；本效果的 focus 不是跨路由幕布。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。
