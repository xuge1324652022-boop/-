# 人物照片收框与工具弹出场景

同一张4:3人物原图从视口中央的自然比例取景框，随滚动迁移到身份介绍右侧的终点框。框使用clip-path、原图使用transform，两者读取同一测量结果；工具按钮在行程后段才开放交互，第一次可见时弹出一次。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 在AboutView式页面中传lang、active与activeTool，监听update:activeTool或使用v-model:active-tool。
2. 保留源图4:3尺寸和CSS层次；更换原图时同步修改sourceWidth/sourceHeight及相关布局比例。
3. 保留motionLayout准备队列及主题CSS变量，确保字体落位后共享刷新。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。

## 维护

修改根目录 `src/`、`动效组件库/效果定义/人物照片收框与工具弹出.json` 或 [命名映射](../../命名映射.json)，再运行 `npm run build:motion`。用 `npm run check:motion` 检查 JSON、中文导入闭包及原文/副本哈希。

状态：`active`。关联效果：[真实视觉行文字揭示](../真实视觉行文字揭示/效果介绍与解析.json)、[海报空间叠层与离场](../海报空间叠层与离场/效果介绍与解析.json)。
