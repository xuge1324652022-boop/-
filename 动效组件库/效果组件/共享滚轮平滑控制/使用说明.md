# 共享滚轮平滑控制器

精确指针设备使用原生RAF与指数曲线推进window.scrollTo，并同步ScrollTrigger.update；尊重原生内部滚动、路由锁与调色页闸门。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 每个页面只保留一个滚轮控制器。
2. 普通子页由App挂载；调色页关闭App控制器并由ColorView传入gate。
3. 为内部滚动区域保留overflow:auto或data-native-scroll，保留所有全局锁类。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。

## 维护

修改根目录 `src/`、`动效组件库/效果定义/共享滚轮平滑控制.json` 或 [命名映射](../../命名映射.json)，再运行 `npm run build:motion`。用 `npm run check:motion` 检查 JSON、中文导入闭包及原文/副本哈希。

状态：`active`。关联效果：[调色首屏滚动闸门](../调色首屏滚动闸门/效果介绍与解析.json)、[全站弧形路由幕布](../全站弧形路由幕布/效果介绍与解析.json)、[动效布局刷新调度](../动效布局刷新调度/效果介绍与解析.json)。
