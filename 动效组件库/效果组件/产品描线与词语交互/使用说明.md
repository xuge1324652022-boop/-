# 产品主题描线与词语交互动效

每个实习产品章节的小型SVG/CSS交互演示。图形首次真实可见后描线一次，圆球与块在可见期间循环；词语按钮切换产品语义和图形姿态，鼠标只通过局部CSS变量制造视差。该效果不使用GSAP，与海报原图碎片遮罩分开管理。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 在产品章节中传theme和lang；源项目从INTERNSHIP_MOTION_THEMES按group.id取配置。
2. 通过referenceIntroductionGate关联页面加载幕；保留IntersectionObserver对实际卡片的观察。
3. 新增主题时按InternshipMotionTheme提供非空words、kind和配色；SVG分支目前为guidance/laser/lawn。
4. 与原版海报并置可说明产品语义，完整作品查看由相邻MotionCard承担。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。

## 维护

修改根目录 `src/`、`动效组件库/效果定义/产品描线与词语交互.json` 或 [命名映射](../../命名映射.json)，再运行 `npm run build:motion`。用 `npm run check:motion` 检查 JSON、中文导入闭包及原文/副本哈希。

状态：`active`。关联效果：[海报局部碎片揭示](../海报局部碎片揭示/效果介绍与解析.json)、[海报空间叠层与离场](../海报空间叠层与离场/效果介绍与解析.json)。
