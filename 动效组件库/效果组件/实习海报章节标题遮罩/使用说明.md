# 实习海报章节标题遮罩

海报编排层将章节标题的内层文字从行遮罩下方揭示一次；作品碎片、CSS演示和空间叠层由下层效果分别负责。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 传入groups和lang，按当前产品组数据建立章节结构。
2. 父页面provide(referenceIntroductionGate)控制何时可触发。
3. 保持标题外层裁切、内层位移结构；监听open事件交给页面查看器。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。

## 维护

修改根目录 `src/`、`动效组件库/效果定义/实习海报章节标题遮罩.json` 或 [命名映射](../../命名映射.json)，再运行 `npm run build:motion`。用 `npm run check:motion` 检查 JSON、中文导入闭包及原文/副本哈希。

状态：`active`。关联效果：[真实视觉行文字揭示](../真实视觉行文字揭示/效果介绍与解析.json)、[海报局部碎片揭示](../海报局部碎片揭示/效果介绍与解析.json)、[海报空间叠层与离场](../海报空间叠层与离场/效果介绍与解析.json)、[产品描线与词语交互](../产品描线与词语交互/效果介绍与解析.json)。
