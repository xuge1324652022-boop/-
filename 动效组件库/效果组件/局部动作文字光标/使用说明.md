# 局部动作文字光标

在声明了真实动作的作品区域显示实心点与双语动词，原生 RAF 对位置做指数追随，Vue Transition 与 CSS 接力替换文字。页面滚动或动画时短时重新命中，静止后停止采样。配套 useCursor 仅提供画廊共享锁状态；本实现不使用 GSAP。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 在应用根只挂载一份 CustomCursor，Teleport 会把视觉层放入 body。
2. 在真实按钮/链接声明 data-cursor 或 data-cursor-label，可提供 data-cursor-zh/en。
3. 原生控件区域声明 data-cursor="native"；纯色舞台按需提供 data-cursor-blend="normal" 与有效 CSS 颜色。
4. 拖拽流程通过 cursorLockState 写 drag，聚焦/返回锁定写 locked，交互结束置 null；保留全局样式的区域限定。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。
