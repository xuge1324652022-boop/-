# 海报色域收缩、空间叠层与侧转离场

为V10L原稿12–15构建连续滚动场景：满屏色域、实字和原图先收为首张海报，再让三张附属稿依次从下方进入，正面停留阅读后侧转65度随页面离场。纸张空间运动可倒放，纸内碎片标题通过introduced/settled记忆只揭示一次。

先读取 [效果介绍与解析.json](./效果介绍与解析.json)，了解触发时机、动画阶段、时序、状态、依赖、接入、清理、交互分支、限制与验证方法。

这是当前仓库的源码阅读与迁移包，尚未封装为独立 npm 包。`源码/` 的中文文件已改写本地导入，并包含入口的传递依赖；`集成示例/` 只保留调用方参考，不作为本包构建入口。

## 接入顺序

1. 原集成从demo-measure组筛选四张id为12–15的作品，按原序传items；主纸面采用0.787比例的实字版式。
2. 监听open接入查看器，并通过referenceIntroductionGate关联加载幕。
3. 保留四层DOM、motionLayout、InternshipAnimatedArtwork及ReferenceIntroduction依赖；换成通用作品需重新设计layers、首稿实字与比例。

在浏览器中的 Vue 3 项目接入。依赖版本见 JSON 的 `npmDependencies`；全局样式见 `源码/项目源码/全局样式.css`。公开媒体与字体资源按 `integration.assets` 提供，授权边界见根目录 NOTICE。源码标识符与外部资源 URL 保留原应用约定。

## 维护

修改根目录 `src/`、`动效组件库/效果定义/海报空间叠层与离场.json` 或 [命名映射](../../命名映射.json)，再运行 `npm run build:motion`。用 `npm run check:motion` 检查 JSON、中文导入闭包及原文/副本哈希。

状态：`active`。关联效果：[实习海报透视叠层](../实习海报透视叠层/效果介绍与解析.json)、[海报局部碎片揭示](../海报局部碎片揭示/效果介绍与解析.json)、[真实视觉行文字揭示](../真实视觉行文字揭示/效果介绍与解析.json)。
